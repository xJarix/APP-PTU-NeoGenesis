## Descargar y probar

1. Abre la release de la versión deseada.
2. En Assets, descarga el APK para Android, el EXE portátil o el instalador para Windows.
3. Los archivos SHA256SUMS permiten verificar cada descarga.

Las versiones están marcadas como preliminares para pruebas. 

## Fichas guardadas

Windows portátil e instalado utilizan `%APPDATA%\PTU NeoGenesis` para guardar las fichas. La Beta 1.5 mantiene el identificador y la firma de Android de la Beta 1.4. Puedes trasladar entrenadores entre dispositivos mediante Exportar Ficha e importar el archivo JSON.

## Alcance del archivo

Se han conservado 14 binarios distintos en siete releases. El archivo llamado `PTU-NeoGenesis-test.apk` coincide con el APK Beta 1.0 y no se publica como una versión adicional.

Este repositorio cataloga paquetes ya compilados. Los tags identifican estas compilaciones archivadas y no reconstruyen el historial original del código fuente. Las fichas personales, claves de firma y herramientas locales de compilación no forman parte de este archivo.

Los términos de uso de Pokémon y de PTU NeoGénesis corresponden a sus respectivos titulares. No se añade una licencia nueva a sus recursos.
